# LLM Resume & Job Description Analyzer

A beginner-level LLM project that analyzes a resume against a job description using a locally hosted Llama 3.2 3B model.

The project extracts text from a resume PDF, sends the resume and job description to the LLM, and generates a structured analysis including matching skills, missing skills, strengths, weaknesses, recommendations, and interview questions.

## 🎯 Project Objective

The main objective of this project is to learn the fundamentals of building an application with a Large Language Model (LLM).

This project focuses on understanding:

* Local LLM inference
* Prompt engineering
* Providing context to an LLM
* Structured JSON output
* LLM response handling
* Basic skill matching
* Python and LLM integration

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd LLM_Resume_Job_Analyzer
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Install Ollama

Download and install Ollama on your computer.

After installation, verify:

```bash
ollama --version
```

### 4. Download the Llama model

```bash
ollama pull llama3.2:3b
```

### 5. Test the model

```bash
ollama run llama3.2:3b
```

Example:

```text
Explain what a data analyst does in 2 sentences.
```

## ▶️ Running the Project

Place a resume PDF inside:

```text
uploads/
```

Place a sample job description inside:

```text
data/sample_job_descriptions/
```

Then run:

```bash
cd src
python test_analyzer.py
```

The program will:

1. Extract text from the resume.
2. Read the job description.
3. Extract relevant skills.
4. Perform basic skill matching.
5. Send the resume and job description to Llama.
6. Generate an LLM-based analysis.
7. Display the results.

## 🧠 Key Learning

One important observation from this project is that **keyword-based matching and LLM-based analysis can produce different results**.

For example:

```text
Rule-Based Match: 100%
LLM Match:         60%
```

The rule-based approach mainly checks whether specific skills appear in both texts.

The LLM can consider broader context such as:

* Skill level
* Experience
* Job requirements
* Project relevance
* Missing knowledge
* Contextual similarity

This helped me understand that **keyword matching is different from contextual understanding by an LLM**.

## 🚧 Current Limitations

This is a beginner learning project and has several limitations:

* Uses a small predefined list of technical skills.
* LLM results may vary between runs.
* Llama 3.2 3B has limited reasoning capability compared with larger models.
* Scanned/image-based PDFs are not supported by the current PDF parser.
* The project does not currently use embeddings or RAG.
* The match score generated by the LLM is an approximate assessment, not a validated recruitment score.
